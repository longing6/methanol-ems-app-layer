---
name: sil-test
description: 为指定 P0 模块生成 SIL 测试用例与测试脚本
---

对本命令后面跟随的参数（P0 模块名 / 需求 ID）生成 SIL 测试。若未提供参数，先询问目标模块。

执行步骤：

1. 从需求条目提取该模块的**输入边界、正常工况、故障工况、饱和与除零保护**场景。
2. 生成 Simulink Test 测试用例，包含：
   - 用例名称与对应需求 ID
   - 输入激励（信号名、单位、时间序列）
   - 期望输出（含容差与判定依据）
3. 测试脚本写入 `tests/`，命名 `test_<模块名>.m`。
4. 输出**无法从需求推导的测试假设**清单，交人工确认后再补齐。
5. 生成本地执行指令：`matlab -batch "cd('<项目根>'); test_<模块名>"`。

不要尝试在云端沙箱运行测试。
