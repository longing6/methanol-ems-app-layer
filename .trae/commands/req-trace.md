---
name: req-trace
description: 建立或更新需求追溯矩阵，并输出缺口与冲突清单
---

对本命令后面跟随的参数（需求 ID 范围 / 文件路径 / 层或模块名）建立追溯矩阵。若未提供参数，先询问要覆盖的范围，不要默认全量。

执行步骤：

1. 从 `requirements/` 下读取《需求规范》《VCU 交互规范》《数据清单》的对应章节。
2. 按下面的链路逐条建立映射：

   `需求ID → 层/子系统 → P0模块 → 输入信号 → 输出信号 → 标定量 → 测试用例`

3. 以 Markdown 表格写入 `requirements/traceability/traceability-<范围>.md`。
4. 在文件末尾输出两个清单：
   - **缺口清单**：链路中任一环缺失的需求
   - **冲突清单**：需求规范与 VCU 交互规范不一致之处，附双方原文位置
5. 只做追溯与差异分析，不要修改任何模型文件。

输出时先给结论：覆盖 X 条 / 缺口 Y 条 / 冲突 Z 条。
