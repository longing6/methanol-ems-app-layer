---
name: codegen-check
description: 对指定模型执行 C 代码生成，并做接口与命名一致性检查
---

对本命令后面跟随的参数（模型名 / 层名）执行代码生成与一致性检查。若未提供参数，先询问目标模型。

执行步骤：

1. 生成调用 Embedded Coder 的脚本（固定代码生成配置：目标、编译器、浮点/定点选项），写入 `scripts/`。
2. 说明预期的产物路径（`*_ert_rtw/` 等），并确认这些目录已在 `.gitignore` 中排除。
3. 生成本地执行指令：`matlab -batch "cd('<项目根>'); <脚本名>"`。
4. 代码生成完成后（用户回传结果），执行一致性检查：
   - 生成的接口与《需求规范》中的接口定义逐项比对
   - 命名是否符合 MAAB / 项目命名规范
   - 是否存在未覆盖的 P0 模块
5. 输出差异表（接口差异 / 命名违规 / 未覆盖项），并给出修正建议。

不要尝试在云端沙箱执行代码生成。
