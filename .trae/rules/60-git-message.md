# 提交信息规范

## 格式

```
<type>(<scope>): <中文简述>

<正文：为什么改，而非改了什么>
```

## type 取值

| type | 用途 |
| --- | --- |
| feat | 新增模块、新增控制功能 |
| fix | 修复模型或脚本缺陷 |
| refactor | 结构调整，不改变功能行为 |
| cal | 标定数据变更 |
| test | 测试用例或测试脚本 |
| docs | 文档 |
| chore | 构建、工具链、配置 |

## scope 取值

使用层名或模块名，例如 `torque`、`L07_thermal`、`P0_23`。

## 要求

- 简述用中文，不超过 50 字，聚焦"为什么"。
- 一次提交只做一件事，不混入无关的格式化改动。
- 提交信息中**不得**出现标定数值、阈值、客户名称或任何敏感信息。
